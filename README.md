# Python Core Logic Suite

A collection of four independent Python projects focused on fundamental algorithms, data manipulation, mathematical feedback loops, and stochastic simulation. This repository demonstrates clean code practices, logic isolation, and algorithmic efficiency.

## Projects Overview

### 1. Crypto (`crypto.py`)
A privacy-focused utility designed to secure plaintext data. It implements data obfuscation to encrypt and decrypt strings, providing a baseline understanding of cryptography, key/shift mechanics, and data integrity.
* **Key Features:** Text parsing, reversible character mapping, and secure terminal-based inputs.

### 2. Math Tutor (`math-tutor.py`)
An interactive CLI educational application designed to test arithmetic proficiency. The program dynamically generates multiplication problems, tracks user inputs, scores performance metrics in real-time, and provides constructive logic loops for learning.
* **Key Features:** Random number generation, condition-based scoring systems, and infinite game/session loops.

### 3. Palindromes (`palindromes.py`)
An algorithmic solver built to identify, verify, and generate palindromic strings in a highly optimized manner. This script focuses on reducing time and space complexity ($O(n)$ time complexity) when handling large string arrays or multi-word sentences.
* **Key Features:** String reversing logic, whitespace/punctuation filtering, and efficient pointer comparisons.

### 4. Trading Game (`trading-game.py`)
A text-based simulation exploring game theory and probability. Users manage a virtual bankroll to bet on the colors of marbles drawn completely at random from a dynamic pool, showcasing risk assessment and random distribution mechanics.
* **Key Features:** Stochastic modeling (`random` module tracking), state/currency persistence, and risk-reward calculation.

## Getting Started

### Prerequisites
Make sure you have Python 3.x installed on your local machine.

### Installation & Execution
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/python-logic-suite.git
   ```
2. Navigate into the directory:
   ```bash
   cd python-logic-suite
   ```
3. Run any of the applications directly:
   ```bash
   python crypto.py
   python math-tutor.py
   python palindromes.py
   python trading-game.py
   ```
